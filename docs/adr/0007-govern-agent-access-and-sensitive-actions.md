# ADR-0007 — Govern Agent access and sensitive actions

**Status:** Accepted
**Date:** 2026-08-14

## Decision
O Agent acessa dados/modelos somente por tools governadas. Não recebe conta
administrativa. Ações sensíveis exigem human-in-the-loop tecnicamente
enforceable e auditável.

## Consequences
Melhora segurança e auditabilidade, com maior esforço de contratos e políticas.
