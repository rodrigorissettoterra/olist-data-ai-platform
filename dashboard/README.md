# Streamlit Dashboard

**MVP status:** Implemented.

The dashboard consumes the governed DuckDB Metrics/Gold layers and provides:

1. Executive Overview
2. Sales & Customers
3. Operations & Logistics
4. Predictive & AI Insights

Run:

```powershell
.\.venv\Scripts\python.exe -m streamlit run .\dashboard\app.py
```

Open:

```text
http://localhost:8501
```

Preview:

![Executive Dashboard](../docs/assets/dashboard-executive-overview.png)

The dashboard is currently local-only; the repository does not claim a public hosted deployment.
