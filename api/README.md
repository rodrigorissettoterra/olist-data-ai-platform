# FastAPI Serving

**MVP status:** Implemented.

The API serves analytical KPIs, model evaluation metadata and order-level delivery-delay predictions.

Endpoints:

- `GET /health`
- `GET /api/v1/kpis`
- `GET /api/v1/model/metrics`
- `GET /api/v1/predict/{order_id}`

Run:

```powershell
.\.venv\Scripts\python.exe -m uvicorn olist_api.main:app `
    --app-dir .\api\src `
    --port 8000
```

Swagger UI:

```text
http://127.0.0.1:8000/docs
```

The API reads the DuckDB warehouse and persisted model artifact generated by the local MVP pipeline.
